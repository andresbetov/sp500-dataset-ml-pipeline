# ADR template

Copy this file to `NNNN-<short-slug>.md` with the next free number. Numbers are
never reused. Once accepted, an ADR's content is frozen — supersede it with a
new ADR instead of rewriting it.

# ADR NNNN: <title>

- **Status:** proposed | accepted | superseded by NNNN
- **Date:** YYYY-MM-DD
- **Scope:** <what this decision covers>

## Context

Why this decision was needed. What was true at the time.

## Decision

What was decided, concretely.

## Alternatives considered

What else was on the table, and why each was rejected. Name the real
trade-off, not a strawman.

## Consequences

What follows from this decision — what gets easier, what gets harder.

- **Revisit trigger:** the concrete condition under which this decision
  should be re-opened.

## Evidence

File:line anchors or observable facts backing the decision. Link the code,
not the conversation.
